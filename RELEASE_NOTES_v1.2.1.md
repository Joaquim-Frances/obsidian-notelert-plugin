# Notelert Plugin v1.2.1

This patch makes multi-channel reminders clearer and easier to control at the
moment they are created.

## Highlights

- **Choose channels per reminder:** the notification modal now shows the
  channels enabled in settings, so each reminder can use the right combination.
- **One shared notification allowance:** the plan card and progress bar now
  represent reminders sent through all channels instead of appearing to be an
  email-only limit.
- **Faster Android setup:** the Android section includes a collapsible setup
  panel with a direct link to Notelert on Google Play.
- **Cleaner language setting:** the misleading pattern-detection subtitle has
  been removed.
- **Obsidian review cleanup:** replaced the broad CSS `:has()` selector with an
  explicit selected-state class.
