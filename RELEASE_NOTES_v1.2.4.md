## Notelert 1.2.4

### Correcciones de release

- Corregida la gestión asíncrona del seguimiento de Stripe en el selector de fecha.
- Eliminada una variable de calendario sin uso.
- El pipeline de publicación solo admite tags de versión inmutables que coincidan con el manifest, garantizando que el código fuente y los assets publicados se construyan desde el mismo commit.

Incluye las mejoras de recordatorios, calendario y entrega de la serie 1.2.x.
